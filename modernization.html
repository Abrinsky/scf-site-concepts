Executive Summary for Leadership & IT

Modernizing siouxcityfoundry.com: Why Replace Dreamweaver & Lasso 9

A factual snapshot of what is currently running on the live corporate site, why routine updates (like spam protection and job postings) burn IT time, and how a modern ~$0 to $20/month stack fixes every issue permanently.

Verified Live Audit (November 2026)

What is currently running on live siouxcityfoundry.com

Every item below was observed directly from live HTTP headers and HTML source on /, /employ.lasso, and /contact.

Area Current Live Site (Observed) Business / IT Impact Proposed Modern Stack
SSL / HTTPS Security Cert Chain Error
Windows curl / Python SSL reject TLS with SEC_E_UNTRUSTED_ROOT (missing intermediate cert).		 Strict corporate firewalls, link previews, and automated procurement tools can flag or block the site. Auto-Managed SSL
Cloudflare Pages issues and renews valid edge certificates automatically.
Mobile & Browser Support Forces IE=7 compatibility mode, zero mobile viewport meta tag, fixed-width Dreamweaver CS5 templates (HTML5_twoColFixRtHdr.css), 2012 Adobe Spry menu. Difficult to read on phones (where job applicants and field buyers browse); brittle HTML caused the broken homepage footer bug. Responsive CSS Grid/Flexbox tested at mobile, tablet, desktop, and clean print-to-PDF stylesheets.
Dead Third-Party Scripts Loads dead Google Code html5shiv (shut down 2015, over http://), dead AddThis widgets (shut down 2023, loaded twice), retired Google UA-1064417-1 (2023), EOL jQuery 2.2.4 (2016). Slow page loads, mixed-content warnings, and unnecessary security surface. Zero legacy plugins, zero jQuery, ~15 KB Alpine.js only where needed; sub-second global CDN load times.
Contact & Spam Protection /contact loads Google reCAPTCHA 5 times + Cloudflare Turnstile twice + a broken client-side <script src=".../turnstile/v0/siteverify"> tag, mixed with Formoid, EmailJS, Mailchimp, and iContact. Explains why spam blocking took weeks to wrestle into place and still breaks easily on template edits. One clean RFQ form verified server-side by a 30-line Cloudflare Worker + Turnstile endpoint, routing directly to division emails.
Jobs & HR Publishing FileMaker + Lasso 9 renders every job as a POST form (/employment/job_id.lasso). HR fills clunky FileMaker text boxes. Job listings have no direct shareable URL for Indeed, LinkedIn, or texting candidates. IT maintains legacy Lasso middleware. Clean web admin (Headless CMS or Cloudflare D1 + Access M365 login): HR clicks Published/Draft in 15 seconds, live immediately with shareable URLs.
Page Edits & Maintenance Static .dwt templates edited manually in Adobe Dreamweaver. Simple text updates risk breaking layout markup; duplicated copy drifts across pages. Component-based Astro templates in Git + automated deploys on push; dynamic content (jobs/news/PDFs) updated by staff without code deploys.
Recommended Production Architecture

Zero Dreamweaver. Zero Lasso. Zero WordPress Plugin Rot.

Built on Cloudflare (which SCF already uses for Turnstile) so IT owns one clean, ultra-reliable account.

Layer 1 · Hosting & Edge

Cloudflare Pages + Astro

Fast static/hybrid marketing pages, automatic HTTPS, DDoS protection, global CDN, and zero Apache/Dreamweaver server maintenance. Cost: $0/mo on Cloudflare Pages free tier.

Layer 2 · Dynamic Jobs & News

Cloudflare D1 + Access Admin (or Sanity CMS)

HR logs in with their Microsoft 365 SCF email, adds/edits jobs or news, and flips a Published switch. Public pages update live with zero site rebuilds and zero FileMaker/Lasso middleware. Cost: $0 to $20/mo.

Layer 3 · Forms & ERP Option

Cloudflare Workers + Turnstile

One clean serverless endpoint verifies Turnstile properly and routes RFQs to the right division inbox. FileMaker stays focused on internal ERP; optional FileMaker Data API webhook can sync later if desired.
